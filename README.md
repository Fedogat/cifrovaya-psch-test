# Цифровая ПСЧ · Тестирование 3.2.1

Отдельный интерфейс для прохождения тестов, назначенных в модуле «Боевая подготовка».

- использует общую Supabase-авторизацию Цифровой ПСЧ;
- получает только назначения текущего сотрудника;
- не передаёт правильные ответы в браузер;
- проверяет результат на сервере и автоматически записывает оценку в занятие;
- поддерживает ограничение времени и количества попыток.

Production URL: `https://cifrovaya-psch-test.vercel.app`.
