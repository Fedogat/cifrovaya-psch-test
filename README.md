# Цифровая ПСЧ · Тестирование

Production URL: https://cifrovaya-psch-test-mocha.vercel.app

Общая Supabase-авторизация с основным сайтом. Правильные ответы остаются на сервере.

Квартальный зачёт: случайные 5 из утверждённых 15 вопросов каждой пройденной темы, перемешивание вопросов и вариантов ответов. За 5/4/3 правильных — оценка 5/4/3; за 0–2 — 2. Сохраняются оценки по темам и средние по предметам; теория автоматически переносится в основную либо дополнительную квартальную ведомость. Практические нормативы не изменяются.
